# Hidra Tecnical — landing (proof of concept)

Single-file dark landing page for [hidratecnical.com](https://hidratecnical.com/): WebGL ribbon hero with 2D fallback, pinned horizontal sections, canvas animations, full `prefers-reduced-motion` support. No build step.

```sh
python3 -m http.server 8799   # then open http://127.0.0.1:8799/
```

- `index.html` — the page
- `img/` — web-ready images used by the page (logo silhouettes, product photos, favicon)
- `assets/hidratecnical/` — originals extracted from hidratecnical.com (GoDaddy stock photos excluded)
